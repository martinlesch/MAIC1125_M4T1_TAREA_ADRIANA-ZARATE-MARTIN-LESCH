# Dataset y clases

Utilizamos un dataset optimizado en Roboflow para identificar maquinaria en entornos de construcción complejos.

**Clases:** 
1. Torregrúa: Activo crítico de coste fijo diario.
2. Excavadora: Activo de coste variable por hora de operación.

**Split:** 80% Entrenamiento / 20% Validación.

**Enlace al Dataset:** [https://universe.roboflow.com/martins-workspace-7mzhv/maic_m4t3_tarea]
